# A Shower of Joy

An entry for make.fun's ai-happy-01, "Make the AI judge happy".

The image: a laughing baby elephant spraying a sparkling shower of water
over three giggling ducklings in a sunlit puddle, a faint rainbow in the
mist. One big joyful moment, drawn as a warm storybook illustration.

`main.py` copies the bundled `entry.png` to the output path the grader
sets (`MAKEFUN_OUTPUT_DIR`, or `/output`).
